# 👟 Drip Store - Full-Stack E-Commerce (Front-End)

> Aplicação de e-commerce moderna, responsiva e de alta performance desenvolvida em **React, Vite e Tailwind CSS**.

---

## 🎯 Sobre o Projeto
O **Drip Store** é uma plataforma de comércio eletrônico focada no mercado de streetwear, calçados e acessórios. O sistema foi construído priorizando a **Experiência do Usuário (UX)** e boas práticas de desenvolvimento front-end, integrando navegação por rotas protegidas, gestão de estado global do carrinho, filtros dinâmicos e um fluxo de checkout altamente realista.

---

## 🛠️ Tecnologias e Arquitetura
- **React 18 & Vite:** Construção de componentes modulares e empacotamento ultrarrápido.
- **React Router DOM:** Gerenciamento de rotas SPA (Single Page Application) e rotas protegidas.
- **Tailwind CSS:** Estilização utilitária focada em design system responsivo e limpo.
- **Lucide React:** Biblioteca de ícones vetoriais modernos.
- **Persistência Local:** Utilização avançada de `localStorage` para sincronização de carrinho, wishlist, histórico de pedidos e autenticação.

---

## ✨ Principais Diferenciais e Funcionalidades
* **Catálogo Inteligente:** Filtros cruzados em tempo real por categorias (*Tênis, Bonés, Headphones, Camisetas, Calças*), marcas, gênero e um *slider* interativo de faixa de preço.
* **Ordenação Dinâmica:** Classificação instantânea por relevância, menor preço, maior preço e ordem alfabética (A-Z).
* **Modal Quick Buy Adaptativo:** Seleção inteligente de atributos — numeração padrão para calçados e **Tamanho Único** com acabamentos/cores específicos para bonés e headphones.
* **Checkout com Máscaras & PIX:** Validação estrita de campos obrigatórios, formatação automática em tempo real para *CPF, CEP, Telefone e Cartão*, além de um painel de **PIX Interativo com botão de copiar chave**.
* **Resiliência e UX Defensiva:** Tratamento de estados vazios (*Empty States*), fallbacks automáticos de imagens por categoria e rota **404 Personalizada**.

## 📦 Como Executar o Projeto

```bash
# Clone o repositório
git clone [https://github.com/MateusTalmagTeixeira/projeto-frontend.git](https://github.com/MateusTalmagTeixeira/projeto-frontend.git)

# Acesse a pasta do projeto
cd projeto-frontend

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
