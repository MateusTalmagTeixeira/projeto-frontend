# Drip Store / Digital Store 🛍️

Aplicação web full-stack desenvolvida como parte de entrega académica e projeto de e-commerce, integrando catálogo de produtos, carrinho de compras e rotas dinâmicas.

## 🌐 Deploy & Ambiente de Produção
* **Acesso Online:** [Digital Store na Vercel](https://projeto-frontend-kappa.vercel.app)

* **Desenvolvimento Front-End & UX/UI**
* **Arquitetura de Componentes & Integração de APIs**
* **Code Review & Otimização de Build (Vite / Vercel SPA Routing)**

## 🚀 Como Executar o Projeto Localmente

1. Clona o repositório:
```bash
git clone https://github.com/lariissantoz/projeto-frontend.git
```

2. Acede à pasta do projeto:
```bash
cd projeto-frontend
```

3. Instala as dependências:
```bash
npm install
```

4. Inicia o servidor de desenvolvimento:
```bash
npm run dev
```
