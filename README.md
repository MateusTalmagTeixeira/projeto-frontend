# 👟 Drip Store - Front-End

> Aplicação de e-commerce moderna, responsiva e de alto desempenho desenvolvida em **React, Vite e Tailwind CSS** como parte de entrega acadêmica em dupla.

---

## 🚀 Sobre o Projeto
O **Drip Store** simula um e-commerce corporativo voltado para o mercado de streetwear, tênis, bonés e acessórios, com foco em **experiência do usuário (UX)**, navegação fluida, filtros avançados e checkout completo.

---

## ✨ Principais Funcionalidades
* **Catálogo Dinâmico & Filtros:** Filtragem em tempo real por categorias, marcas, gênero e faixa de preço.
* **Ordenação de Produtos:** Classificação por relevância, menor preço, maior preço e ordem alfabética.
* **Modal Quick Buy:** Seleção dinâmica de tamanhos e cores antes de adicionar ao carrinho.
* **Carrinho & Checkout:** Máscaras automáticas (CPF, CEP, Telefone, Cartão) e **PIX Interativo** com botão de copiar.
* **Rotas Protegidas:** Páginas de *Pedidos* e *Wishlist* com autenticação e persistência via `localStorage`.

---

## 🛠️ Tecnologias
- React | Vite | React Router DOM | Tailwind CSS | Lucide React | Vercel
