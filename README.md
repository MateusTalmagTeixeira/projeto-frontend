## 📋 Sobre o Projeto
O **Drip Store** é uma aplicação web de comércio eletrónico desenvolvida com foco em performance, componentização modular e experiência de utilizador (UX). O sistema integra gestão de rotas do lado do cliente, catálogo dinâmico de produtos e carrinho de compras interativo.

---

## ⚙️ Como Executar o Projeto Localmente

Certifica-te de que tens o [Node.js](https://nodejs.org/) instalado na tua máquina.

```bash
# 1. Clona o repositório
git clone https://github.com/lariissantoz/projeto-frontend.git

# 2. Navega para o diretório
cd projeto-frontend

# 3. Instala as dependências
npm install

# 4. Inicia o servidor de desenvolvimento
npm run dev
```
